## 2. The idea

Split the live discount signal into two sleeves, each built separately and banded
at the spec's `band_width`:

- a **within-group** sleeve;
- a **between-group** sleeve, over the groups multi, hy, muni and loan.

Give each sleeve a budget derived from its fit-period IR and correlation,
`(v_w, v_b) ∝ (IR_w − ρ·IR_b, IR_b − ρ·IR_w)`. Compare the result with LIVE at
matched turnover.

This re-weights the existing signal (Job 1, breadth). It is not a new source of IC.

**Mechanism and who loses.**

- **Within:** single-ticker retail flow (yield chasers, and holders selling one
  name) moves one fund's discount against siblings that hold the same assets. The
  effect survives because:
  - the share count is fixed and there is no AP;
  - CEF borrow is dear. The mean fee on held shorts was 11.1–23.0%/yr by group
    at IBKR, 2021-09 → 2022-12 [S: W10-B §7; `python3 scripts/cef/w10_partb.py`].
- **Between:** group-wide flows that partly reprice fundamentals: leverage cost,
  duration, and muni tax-loss selling. They give at most three independent
  spreads.

## 6. Reproducing the figures

**The held-book mix in §4** [V] (the W10-B rule; `scripts/cef/w10_partb.py`
`sec_today` reads only the 2026-10-10 snapshot):

```python
import json
grp = {t: 'multi' for t in ['BIT','DSL','PCN','PDI','PDO','PFN','PHK','PTY']}
grp.update({'AWF': 'hy', 'HYT': 'hy', 'MHD': 'muni', 'MQY': 'muni', 'JFR': 'loan'})
for d in ['2026-10-10', '2026-10-13', '2026-10-14', '2026-10-15']:
    s = json.load(open(f'results/ops/alpaca_probe/{d}_cef.json'))
    eq = float(s['account']['equity'])
    w = {p['symbol']: float(p['market_value']) / eq for p in s['positions']}
    assert set(w) <= set(grp)
    B = W = 0.0
    for g in ['multi', 'hy', 'muni', 'loan']:
        held = [t for t in grp if grp[t] == g and w.get(t, 0) != 0]
        if held:
            b = sum(w[t] for t in held) / len(held)
            B += abs(b) * len(held); W += sum(abs(w[t] - b) for t in held)
    print(d, round(B / (B + W), 3))
```

**The arithmetic in §3** [U] (inputs [S] from W10-B §5):

```python
import math; from statistics import NormalDist; N = NormalDist()
IRw, IRb, rho = 1.03, 0.19, 0.015
sr = lambda vw, vb: (vw*IRw + vb*IRb) / math.sqrt(vw*vw + vb*vb + 2*rho*vw*vb)
vw, vb = IRw - rho*IRb, IRb - rho*IRw
lw, lb = 5.38, 3.57                                    # LIVE's leg vols
print(vb/(vw+vb), sr(vw, vb))                          # derived: share 0.145, SR 1.045
print(lb/(lw+lb), sr(lw, lb), sr(vw, vb) - sr(lw, lb)) # LIVE: 0.399, 0.957; gain 0.088
r = lb/lw; print((r*IRw + rho*IRw) / (1 + r*rho))      # IR_b at which LIVE is optimal: 0.692
cov = lambda a, b: a[0]*b[0] + a[1]*b[1] + rho*(a[0]*b[1] + a[1]*b[0])
print(cov((lw, lb), (vw, vb)) / math.sqrt(cov((lw, lb), (lw, lb)) * cov((vw, vb), (vw, vb))))  # 0.916
for Y, g in [(9.5, 0.088), (9.5, 0.035), (18, 0.01), (18, 0.03)]:
    se = math.sqrt(2*(1 - 0.92)/Y)                     # SE of the Sharpe difference
    print(Y, g, 1 - N.cdf(1.96 - g/se), 1 - N.cdf(2.818 - g/se))
print(1 - N.cdf(2.818 - 0.96*math.sqrt(9.5)))          # LIVE clears 2.818 on its level: 0.556
```
