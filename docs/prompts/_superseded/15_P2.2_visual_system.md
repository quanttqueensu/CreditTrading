## Paste from here

You are tightening the visual system of the QUANTT CEF dashboard
(`dashboard/static/index.html`, inline CSS at the top of the file, tokens
under `:root`, dark values under both the media query and
`[data-theme="dark"]`). Read the CSS block in full and the comment above
the tokens about the palette and fixed categorical slots. Run P2.1 first;
this prompt styles the five-screen layout.

The reference is a professional trading blotter: dense, quiet, every
number aligned, colour only where it carries a verdict. Not a marketing
page, not a BI tool.

### The system

**Type.** One modular scale, five sizes, nothing else:

| role | size | face | weight | tracking |
|---|---|---|---|---|
| screen heading | 15px | Inter | 600 | −0.01em |
| body / labels | 13px | Inter | 400 / 500 | 0 |
| table cells, numbers | 12px | JetBrains Mono, `font-variant-numeric: tabular-nums` | 400 | 0 |
| column headers, units | 11px | Inter | 500 | +0.02em, sentence case, never all-caps with tracking |
| KPI value | 20px | Inter | 600 | −0.02em, proportional-nums |

No 9.5px uppercase micro-labels. If a label needs to be that small it is
not needed.

**Colour.** Neutrals (plane, surface, raised, sunken, ink, ink-2,
ink-muted, hair, axis, grid) plus exactly:

- `--good`, `--warn`, `--crit` for status, each with a bg/ink pair;
- `--cheap` / `--rich` for the signal's two poles;
- `--up` / `--down` for signed P&L.

Delete the eight categorical series slots `--s1`…`--s8`; today no chart
has more than three series, and when the benchmark chart returns it gets
strategy = ink, benchmarks = ink-muted with dash patterns, not hues. Keep
the `[data-theme]` double declaration so the toggle wins both ways.

**Density.** 8px grid. Table rows 28px. Card padding 12px 14px. No card
inside a card; where a boundary carries meaning use a card, otherwise a
1px hairline rule. KPI tiles are a single row of at most six, never a
grid of eight.

**Glyphs.** Replace every unicode glyph (◇ ▢ ✓ ! ◷ ⚠ ✓) with a 12px inline
SVG set defined once in a `<symbol>` sprite: check, alert, dot, clock,
lock. Or no glyph; a coloured chip with a word is usually enough.

**Motion.** Keep the 0.9s flash on a changed cell. Remove the pulsing
freshness dot; freshness is a timestamp.

**Units.** In the column header, once, never in the cell. Signed values
carry a real minus (U+2212) as today. Money has no decimals above $1,000.

**States.** A stale value is greyed with its timestamp, not hidden. An
unavailable value is `nodata()` with the server's reason. A loading value
is a hairline skeleton, not "loading…" text.

**Print.** `@media print`: screens 3 and 4 fit one landscape page each,
no drawer, no masthead buttons, black on white.

4. Write a 20-line style guide as a comment at the top of the CSS: the
