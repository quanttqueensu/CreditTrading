### The problem with the current number

25.2bp was found by bisecting on turnover until the joint book matched
the band's 14.2×/yr, then rationalised with the formula. The rationale
is right but the number is fitted to a turnover target. A derived number
would let the objective say what turnover *should* be, which is the
point of having an objective.

### The derivation

Write the expected return of a position in name $i$ opened at $t$ and
held for its expected life $H$ as the sum of expected daily returns. Under
the pooled decay, the IC at horizon $h$ is what the audit measured; the
cumulative expected return over $H$ days in Grinold form is

$$\mu_i^{(H)} = IC_H \cdot \sigma_i\sqrt{H} \cdot s_i,\qquad s_i = -(z_i - \bar z),$$

with $IC_H$ read from the term structure (interpolate on $\sqrt h$
between the measured points; beyond 21d use the 31-day half-life decay of
$IC_h/\sqrt h$ that PLAN §2.4 states). Verify the interpolation
reproduces the four measured points.

The single-period objective $w'\alpha - c\lVert\Delta w\rVert_1$ compares
one period of alpha against a whole trade. If α is **replaced** with
$\mu^{(H)}$, the whole-life expected return, then the cost term should be
the whole-trade cost, which is $c_{exec}$ per unit of one-way turnover,
with no correction:

$$c_{model} = c_{exec}\quad\text{when}\quad \alpha_i = \mu_i^{(H)}.$$

Equivalently, keeping α in the current units $\sigma_i s_i$:

$$c_{model} = \frac{c_{exec}}{IC_H\sqrt H}.$$

Note this differs from the script's $c_{exec}/(IC\cdot H)$: the
current formula uses the 1-day IC and a linear $H$; the term-structure
version uses the $H$-day IC and $\sqrt H$. They agree only if
$IC_H \sqrt H = IC_1 H$, i.e. if IC grows linearly in $\sqrt h$, which
the measured term structure says is approximately true out to ~21 days
and not beyond. Show both and the difference.

**$H$ is not free either.** The holding period depends on $c$: a larger
$c$ produces a longer hold. So $H$ and $c$ are a fixed point:

1. start with $H_0$ = the band's measured hold (from
   `evaluate(band(T, 0.048), R)["hold"]`),
2. compute $c_{model}(H_0)$, run the joint optimiser, measure its hold
   $H_1$,
3. iterate until $|H_{k+1} - H_k| < 0.5$ days. Report the sequence.

λ: recalibrate with `lambda_for_vol` at each step so the $c = 0$ solution
keeps the 6% target; report λ's value so a reader can see it moved with
the units.
